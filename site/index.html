Potatify it.

The opposite of an upscaler. Drop one DLL next to a game's .exe and it renders fewer pixels, loads smaller textures and skips expensive effects, so new, heavy PC games ask far less of a weak GPU or an integrated laptop chip. The game logic is never touched, so it plays exactly the same; it just looks a few console generations older.

How it works

Games don't draw pictures themselves. They send commands to the GPU through DirectX, and DirectX lives in a DLL. Windows looks for DLLs in the game's folder first, so Potatify's DLL gets loaded instead of the real one. It passes every call on to the real DirectX, after editing a few of them.

Game ──commands──► d3d11.dll / d3d12.dll (Potatify) ──edited commands──► System32 DirectX ──► GPU "make a 1920×1080 buffer" → "make a 960×540 buffer" ¼ of the pixels to shade "upload this 4096² texture" → "upload its 1024² mip" 1/16 of the VRAM "16× anisotropic filtering" → "plain bilinear" or "point" fewer texture reads "present the frame" → pixelate + fewer colours first retro look (optional)
01

Gameplay untouched

Positions, hits and timing are computed by the game on the CPU. Potatify only edits drawing commands, so a demade game plays exactly like the original.

02

Menus stay sharp

Only the 3D scene buffers are made smaller. The game's UI still draws at full resolution on top.

03

One click to undo

Remove deletes everything it wrote and restores any DLL or Engine.ini it backed up. Nothing in the game's own files is patched.

Get started in a minute

  1. Download the zip from Releases and run potatify.exe. No installer.
  2. Choose the game folder: the one with the game's .exe. For Unreal Engine games the root folder works too.
  3. Pick a preset and press Install. Start the game. Not happy? Press Remove.

Help measure it

Potatify is new. Its automated tests run on a software GPU, and real-game numbers don't exist yet. Run a game once with the Off preset and the log on, then once with a preset, and share the two logs. That is the most useful contribution right now.

FAQ

Can I use it in online games?

No. Games with anti-cheat (Vanguard, EasyAntiCheat, BattlEye and others) may ban accounts for loading a foreign DLL. Potatify is meant for offline and single-player games, and it does nothing to hide itself.

Will it make every game faster?

Only games limited by the GPU or VRAM. If a game is slow because of the CPU (AI, physics, huge simulations), drawing fewer pixels won't help. It also can't add GPU features your card doesn't have, such as ray tracing or mesh shaders.

Which games does it work with?

DirectX 11 games get every option. DirectX 12 games get filtering and the look options; Unreal Engine games also get lower resolution and textures through their Engine.ini. Vulkan and OpenGL games aren't supported yet.

Only part of the picture shows. What now?

Some games read their screen buffers by pixel position. Set "3D render resolution" back to Full for that game. If the game copies between buffers, Potatify notices, stops scaling, and says so in the log.

Is it safe for my game files?

It only adds files next to the game. Any DLL that already sits there is backed up first (and Potatify refuses to overwrite an existing backup). Engine.ini edits are a marked block, and the original file is kept for Remove.
